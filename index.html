VKU Field Survey Engine • Phiên bản 1.0.0 (Production Build)

Kiến trúc

Three-Layer Architecture

Presentation (MD3 UI) - Business Logic (UUID v4, Canvas Compress, Auto-Sync) - Data (IndexedDB v2, Cache-First SW).

Ngoại tuyến

Offline-First 100%

App Shell Cache-First nạp dưới 1 giây; Real-time Draft Persistence (IndexedDB debounced 450ms) chống mất dữ liệu khi F5.

Đồng bộ

Background Auto-Sync

Tự động điều phối tuần tự khi bắt sự kiện window.ononline, chuyển nhãn PENDING_SYNC sang SYNCED.

Đa nền tảng

Capacitor Native Bridge

Cấu hình sẵn capacitor.config.json, tích hợp Camera/Network Native Plugin để đóng gói file APK Android.
